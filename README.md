# Demo 593IA × Xtrim — venta de internet por WhatsApp

Demo interactiva del canal digital de ventas de WDB S.A. / 593IA para Xtrim, construido sobre Jelou.

- `index.html` — demo con 4 escenarios: venta completa, sin cobertura, cliente no califica y alta del punto de venta. Controles: Reproducir, Probar yo, Paso a paso y velocidad.
- `reel_593ia_xtrim_venta.mp4` — reel vertical 1080×1920 del escenario «Venta completa».

Montos, tarifas, nodo y números de contrato aparecen entre corchetes hasta conectar las APIs de Xtrim. Clientes y tienda son de ejemplo.

Enlaces directos a cada escenario: `#venta`, `#sin-cobertura`, `#no-califica`, `#alta-pdv`.
